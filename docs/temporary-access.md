# Временная ссылка для демонстрации

Полный сайт можно временно открыть через Cloudflare Quick Tunnel. Пользователь
явно разрешил передачу трафика сайта, видео, кадров и данных входа через Cloudflare.
Этот режим включается отдельно от локального запуска; без него внешнего туннеля нет.
Распознавание по-прежнему выполняется локально в CPU-контейнере, без облачной AI-модели.
Рабочий ключ API не публикуется в инструкции, URL, Git или логах.

## Запуск

При запущенном Docker Desktop, настроенном `.env` и собранном образе:

```sh
SITE_ADDRESS=http://localhost docker compose -f compose.yaml -f compose.local.yaml -f compose.tunnel.yaml up -d tunnel
SITE_ADDRESS=http://localhost docker compose -f compose.yaml -f compose.local.yaml -f compose.tunnel.yaml logs --no-color tunnel
```

В выводе найдите адрес `https://…trycloudflare.com`. Откройте его в браузере.
Приложение требует входа/регистрации; аккаунты и результаты используются те же,
что у Docker-версии на `http://localhost:8080`. Swagger доступен по `/docs`.
Для передачи ссылки посетителю не нужен ключ API: браузер использует пользовательскую
сессию. Ключ жюри не встроен в страницу и не должен публиковаться вместе со ссылкой.

Работают два дополнительных контейнера: `tunnel` соединяется с Cloudflare,
`tunnel-origin` принимает только внутренние Docker-запросы и проксирует приложение.
У них нет опубликованных host-портов. Отдельный origin сообщает Uvicorn о публичном
HTTPS, поэтому cookie получает Secure. Исходный IP посетителя берётся из
`CF-Connecting-IP`, предоставленного Cloudflare. Нельзя публиковать origin напрямую:
он доверяет информации туннеля. HTTP-запросы направляются на HTTPS, тело загрузки
ограничивается прокси и приложением. Cache-Control для туннеля — no-store.

## Остановка публичного доступа

```sh
SITE_ADDRESS=http://localhost docker compose -f compose.yaml -f compose.local.yaml -f compose.tunnel.yaml stop tunnel tunnel-origin
```

Локальный сайт и его данные сохраняются. У туннеля отключён автоматический restart:
после перезапуска Docker/компьютера его нужно включить вручную. Новый запуск может
выдать другой hostname. Не включайте tunnel для обычной локальной разработки.
Чтобы остановить всю эту конфигурацию с сохранением томов:

```sh
SITE_ADDRESS=http://localhost docker compose -f compose.yaml -f compose.local.yaml -f compose.tunnel.yaml down
```

## Ограничения

Mac должен оставаться включённым и подключённым к интернету, Docker и контейнер
туннеля — работающими. Сон Mac прерывает доступ. Ссылка временная, без гарантии
доступности и стабильного имени; это демонстрация, не постоянный сервер для жюри.
Через Cloudflare проходит HTTP-трафик, включая загружаемые видео, возвращаемые кадры,
пароли и пользовательские сессии. Если отправить ключ API через этот адрес,
Cloudflare также будет посредником для этого ключа. Проверка с рабочим ключом через
публичный туннель в текущей сессии не выполнялась; для анализа использовалась
авторизованная пользовательская сессия и синтетический аккаунт.

Случайный hostname не заменяет защиту аккаунтов и API. Регистрация доступна всем
посетителям, узнавшим ссылку; общий лимит очереди остаётся прежним. При передаче
приватных банковских записей нужно отдельное разрешение владельца данных.
Ограничения Cloudflare на запросы/загрузки могут сработать раньше лимитов приложения.

## Проверка текущей поставки

Через выданный публичный HTTPS-адрес проверены доступность, документация,
отклонение запросов без ключа и с неверным ключом, регистрация/вход/выход,
Secure/HttpOnly/SameSite cookie, HTTP → HTTPS и обработка синтетического MOV
через пользовательский API до `done` с проверкой схемы результата/JPEG.
Пустой, повреждённый и неподдерживаемый файлы отклоняются, неизвестная задача даёт
404 в пользовательском API. Рабочий API-ключ не передавался: проверка безопасности
не разрешила передачу этого отдельного секрета через Cloudflare.
Реальные записи датасета не использовались; качество распознавания не измерялось.
Агрегаты проверки и текущий адрес хранятся локально в `data/deployment-checks/`,
без ключей, паролей, кадров и описаний сцен. Сам hostname в Git не фиксируется.

Официальная документация: [Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/),
[HTTP-заголовки Cloudflare](https://developers.cloudflare.com/fundamentals/reference/http-headers/).
