# Forte Vision — приложение и API

Ответственный за сервер передаёт проверяющему HTTPS-адрес приложения и ключ API
отдельным приватным сообщением. Адрес ещё не назначен: `YOUR_DOMAIN` ниже — шаблон.

- Приложение: `https://YOUR_DOMAIN/` — самостоятельная регистрация и вход.
- Swagger: `https://YOUR_DOMAIN/docs` — кнопка Authorize, поле X-API-Key.
- Проверка сервера: `https://YOUR_DOMAIN/health` — не оценка качества ML.

## Анализ видео

Задайте `API_KEY` в окружении приватно. Ключ не нужен для входа в браузер и не должен
передаваться в URL. Используйте разрешённую для проверки запись MOV до 100 МиБ,
600 секунд и 16 мегапикселей.

```sh
curl --fail-with-body -X POST 'https://YOUR_DOMAIN/api/v1/analyze' \
  -H "X-API-Key: $API_KEY" \
  -F 'file=@/path/to/video.mov;type=video/quicktime'
```

Ответ HTTP 202: `{"job_id":"..."}`. Опрос статуса, например раз в секунду:

```sh
curl --fail-with-body 'https://YOUR_DOMAIN/api/v1/jobs/JOB_ID' \
  -H "X-API-Key: $API_KEY"
```

`processing` — ожидает или выполняется; `done` — готов результат;
`failed` — анализ не завершён, причина находится в `error`. Повторять загрузку
нужно только при необходимости новой проверки. Ошибка никогда не означает отсутствие
нарушений. По умолчанию серверный бюджет передачи файла, проверки, очереди и анализа —
270 с; получение результата отдельным запросом добавляет время.

При `done` ответ содержит `job_id`, `status`, `verdict` и `violations`.
`verdict` принимает `violation` или `no_violation`. Каждое событие содержит `type`,
`timecode_sec`, `description`, 1–3 `evidence_frames` с `timestamp_sec` и
`image_base64` (JPEG без `data:`-префикса), а также `rule_source`.
Не выводите полный ответ с кадрами в общие журналы и не публикуйте его.

Текущая экспериментальная модель классифицирует 16 типов действий. Поля `type_id`,
`type_confidence`, `description_source` и `rule_context` описывают предполагаемый тип
и условия применения правила. Оценка модели не является вероятностью нарушения.
Каталог правил возвращает `status=provided`, `document` и доступные `section`/`url`
либо `status=unmapped` с причиной в `reason`. Тип действия и применимость правила
требуют проверки человеком. При выборе исходного бинарного checkpoint типы действий
и нормативные источники не назначаются.
Учебные сценарии интерфейса явно обозначены и не являются ответами API.

## Ошибки и ограничения

- `400`: пустой файл; `413`: превышен размер; `415`: неверный формат/повреждённое видео.
- `408`: превышен бюджет передачи и обработки файла.
- `401`: отсутствующий или неверный ключ; `404`: неизвестная либо уже удалённая задача.
- `422`: неверный формат запроса, например отсутствует multipart-поле `file`.
- `429`: занята проверка видео или заполнена очередь; повторить после `Retry-After`.
- `503`: локальная модель отключена или недоступна.

По умолчанию один анализ одновременно, до четырёх задач вместе с очередью.
Хранятся не более 200 завершённых задач и не дольше 24 часов; загруженное видео
удаляется после обработки. Ключ API предназначен для доверенного проверяющего и
даёт доступ к результатам задач; пользовательские сессии браузера ограничены своими
задачами. После установки зависимостей анализ использует локальные веса, без
облачных AI API. Точность финальной модели проверяется командой отдельно.
